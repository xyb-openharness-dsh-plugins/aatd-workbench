# 交互路径（AATD · IP1 v0.1）

> 0 患者访谈。本文件是 Q1 要求的已签认交互路径文档（无人值守自动签认，待晨审追认）。每条路径：入口（逐字=界面文案=导航 key）→ 步骤 → 可观察产物 → 回首页。每页 ≤1 显式编辑入口，手工入口收进「⋯ 更多」。

## 页面清单与覆盖（IP2/X1）

view/sub 全集（10 视图）：home、course、records、labs、chart、treatment、family、mind、review、settings；
sub：course/timeline、course/list、records/lib、records/draft、records/archive、records/panel、records/summary、mind/feel、mind/life；
整页视图 page-* 与疾病概要 primer 不计一级页。

## 通道一致性（IP5/IP9/X3）

- 可写实体：note、metric_record、report、med_event、episode、family_line。每类有手工通道（收进「⋯ 更多」）与 AI 候选通道（拒收零副作用）。
- 手工/AI/导入三入口写同一事实层、同一更正链，无裸删除：更正=新增版本（IP8，「不可恢复」文案 0 命中）。

## AI 协助示例（IP10/IP11）

每个一级页至少一处「和 AI 讨论」携带本页关键信息（事实，无判定词）进输入框，不代发（Q17/Q19）。

## 数字键盘（IP7）

日期/次数/数值输入用数字键盘组件；文本框只用于原话/备注。

## 覆盖断言执行方式

M2 用无头脚本穷举 (view,sub) 覆盖计数与路径逐字走查（X2/X4），输出数字与清单，不写「看过了」。
