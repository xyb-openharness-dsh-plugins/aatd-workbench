# 差异化矩阵（AATD · 防「换名复用」）

病种：α1-抗胰蛋白酶缺乏症（R2 非肿瘤慢性病型）。对照仓：cervical-workbench（客户端链路底本）、aml-workbench（结构基准）、breast-cancer-workbench（成熟对比基准，26 号口径）。全部 0 患者访谈、0 临床审核。

## 一级重名率实测

见 FAMILY-CONTRAST §6：4/12 = 33%（cervical 12 页为对照集），≤70% 达标。重名页（看板/病情一图秀/检查与指标/复诊准备）的内容语义不同，逐页差异见下表。
