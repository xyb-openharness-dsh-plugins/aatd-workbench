# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：α1-抗胰蛋白酶缺乏症患者及家属；覆盖确诊后的病程记录、肺功能与肝功能长期随访、每周加强治疗输注登记和就诊资料准备。家属代记需标明记录者，家系成员筛查线索只记录医生原话，不判定遗传风险。

场景：肺功能单（FEV1/DLCO）、肝功能单（ALT/GGT）、每周输注记录和呼吸科与消化科医生答复散在不同时间与载体中，患者复诊前难以按日期还原经过。工作台按日期整理自述与资料，帮助回看记录、核对来源并准备想问医生的问题，不代替医生判断。

核心流程：
1. 打开工作台，查看最近记录、待核对资料和想带去复诊的问题
2. 记录一次症状、输注或归档一份肺功能/肝功能报告，写清日期、记录者、原文、单位和参考范围，缺失项保留为空
3. 按日期并列回看本人/家属感受、两科报告指标、输注事件与医生原话，不推导因果或疗效
4. 导出就诊准备材料，回去能看到同一份已确认记录

完成结果：患者或家属能把一次记录（症状/输注/报告）核对入库，并在复诊前导出带来源和待问事项的材料；所有自述、报告、AI 候选与医生答复边界清楚，不生成诊断或治疗建议。
