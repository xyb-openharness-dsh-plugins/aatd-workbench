# 患者旅程（AATD · 原创）

0 患者访谈：以下旅程为开发者假设改写，不冒充患者原话；待真实访谈补位。

## 旅程一：刚确诊（档案 A 的患者画像）

1. 拿到基因检测报告（如 Pi*ZZ，占位描述【待核】），第一次听说这个病 → 打开工作台「档案」页，记录医生原话与报告要点，缺失项留空。
2. 被告知要查肺功能、肝功能 → 「报告」页归档两科化验单，指标带方法/单位/机构标注，未出值的项目显式留空。
3. 开始每周加强治疗输注 → 「治疗」页建输注记录，按次登记，漏输的周如实留空。
4. 复诊前 → 「导出」页生成就诊准备材料（含待问清单），带来源。

## 旅程二：长期随访多年（档案 B 的患者画像）

1. 肺功能一年查多次，想知道 FEV1 走势 → 「指标」页按可比组看趋势，跨方法不连线。
2. 出现急性加重住院，出院后记不清日期 → 「病程」页记录发作—缓解区间，近 90 天计数自动更新。
3. 家属想帮忙代记 → 记录者标注切换本人/家属，私密记录三出口过滤。
4. 家系成员问筛查 → 「家系线索」页只看医生原话与条目事实，提示「需要问你的医生」。
